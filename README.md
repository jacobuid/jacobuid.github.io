# jacobuid.github.io

GitHub Pages site for [jacobuid.github.io](https://jacobuid.github.io/) — an
8-bit side-scrolling résumé.

- **[portfolio/](portfolio/)** — the live site (React + NES.css). See
  [portfolio/README.md](portfolio/README.md) for how to run it, add a scene, or
  draw a sprite. `npm run deploy` publishes `build/` to the `gh-pages` branch.
- **[old/](old/)** — the previous AngularJS/jQuery site, kept for reference,
  along with the [sandbox experiments](old/sandbox/) (mario, dart, map,
  tree-view). These are not deployed: the `gh-pages` branch contains only the
  build output, so browse them here in the repo.
