# Recovered source

`MatchBrowserSprite.original.js` is the browser-with-heart sprite as it was
first written, pulled back out of the Claude Code session transcript after the
file had been overwritten. Nothing in the repo is committed yet, so the working
tree was the only copy and the overwrite lost it.

It was created by a shell heredoc rather than a file-write tool, so it was
recoverable only by re-parsing the transcript JSONL for
`cat > .../MatchSprite.js <<'JS' ... JS`. Kept here as a backstop until the
tree is committed.
